# Поиск дубликатов (DupFinder)

**Русский** · [English](README.en.md)

Программа для Windows, которая находит одинаковые файлы — на одном диске или между двумя дисками —
и помогает освободить место: удалить лишние копии в корзину или превратить их в жёсткие ссылки.

Одинаковыми считаются файлы с одинаковым **содержимым**; имя, папка и дата не важны.

Интерфейс — на русском и английском. По умолчанию — как язык Windows; сменить можно списком в конце
строки параметров (применяется после перезапуска, программа предложит его сама).

## Запуск

Готовая программа — один файл `DupFinder.App.exe` (Windows 10/11, 64 бит). Установка не нужна,
.NET ставить не нужно: скопировать куда угодно и запустить. Первый запуск чуть дольше — exe
распаковывает свои библиотеки во временную папку.

## Как пользоваться

1. **Диск A** — выберите диск или папку кнопкой «Обзор…».
2. **Диск B** — по желанию:
   - не указан — ищутся дубли внутри A;
   - указан — сравниваются A и B. С галочкой «Только файлы, которые есть и на A, и на B»
     (по умолчанию) показываются только общие файлы; без неё — вообще все дубли на обоих.
3. **Не меньше … КБ** — файлы меньше этого размера пропускаются. Пустые файлы не учитываются никогда.
4. **Найти дубликаты.** Сканирование можно прервать кнопкой «Стоп».
5. Найденное показывается группами — сверху те, что освободят больше всего места. Буква A/B у файла —
   на каком из дисков он лежит. Двойной щелчок по файлу открывает его в проводнике.
6. **Отметьте, от чего избавиться** — вручную галочками или кнопками:
   - «Оставить самый старый» — в каждой группе остаётся файл с самой ранней датой изменения;
   - «Оставить на A» / «Оставить на B» — отмечаются копии на другом диске.
7. **Что сделать с отмеченными:**
   - **Удалить в корзину** — отмеченные файлы уходят в корзину, их можно восстановить;
   - **Заменить ссылками** — см. ниже.
8. **Отчёт CSV…** — список всех групп для Excel (разделитель — как в региональных настройках).

Причины, по которым что-то не прочиталось или не удалилось, собираются на вкладке «Ошибки».

## Замена ссылками

Отмеченный файл остаётся на своём месте и открывается как прежде, но становится жёсткой ссылкой
на оставляемую копию: данные хранятся на диске один раз. Подходит, когда файл нужен в нескольких
папках, а место — нет.

- Работает только на NTFS и только в пределах **одного** диска: файл на B нельзя сделать ссылкой
  на файл на A. Такие файлы пропускаются с пояснением на вкладке «Ошибки».
- После замены это **один и тот же файл** под разными именами: изменили один — изменились все.
  Для фото и видео-архива это обычно то, что нужно; для документов, которые правятся, — нет.

## Защита от потери данных

- В группе нельзя отметить все копии — программа откажется что-либо делать.
- Перед удалением и заменой проверяется, что файл не изменился после сканирования.
- **Сверять побайтно** (галочка включена по умолчанию) — перед удалением файл сравнивается
  с оставляемой копией байт в байт. Это медленнее, но не полагается на хеш. Для замены ссылками
  сверка выполняется всегда.
- На флешках и картах памяти корзины нет: такие файлы удаляются насовсем, и диалог об этом
  предупреждает отдельно.

## Кэш хешей

Чтобы повторное сканирование того же диска шло секунды, а не часы, программа запоминает хеши файлов
в `%LOCALAPPDATA%\DupFinder\hashcache.db`. Файл перечитывается, если у него изменились размер или
дата. Записи о файлах, которых не было 180 дней, удаляются сами. Кэш выключается галочкой
«Кэш хешей», очищается кнопкой «Очистить». Рядом, в `settings.json`, хранится выбранный язык.

## Как устроен поиск

Чтобы не читать целиком каждый файл, проверки идут от дешёвых к дорогим:
размер → хеш первых и последних 64 КБ → полный хеш (XxHash128). Большинство файлов отсеивается
уже по размеру.

Каждый диск читается в один поток — на HDD параллельное чтение только гоняет головку и замедляет
работу; два разных диска читаются одновременно. Жёсткие ссылки на один файл дублями не считаются,
ярлыки-каталоги (junction, symlink) не обходятся, служебные папки (`$Recycle.Bin`,
`System Volume Information`) пропускаются.

## Сборка из исходников

Нужен .NET 10 SDK.

```
dotnet run --project src/DupFinder.App                        # запустить
dotnet test                                                   # тесты
dotnet publish src/DupFinder.App -p:PublishProfile=SingleFile # один exe → publish/DupFinder.App.exe
```

| Проект | Что внутри |
|---|---|
| `src/DupFinder.Core` | поиск, хеши, кэш, сверка и жёсткие ссылки — без интерфейса |
| `src/DupFinder.App` | окно на WPF (MVVM, CommunityToolkit.Mvvm) |
| `tests/DupFinder.Tests` | тесты xUnit на временных каталогах |

Исходная постановка задачи — `docs/Описание.txt`.
